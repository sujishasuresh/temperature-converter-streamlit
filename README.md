# 🌡️ Temperature Converter

A simple and interactive web application built using **Python** and **Streamlit** to convert temperatures between **Celsius and Fahrenheit**.

The application allows users to select the temperature unit, enter a temperature value, and get the converted result instantly.

## ✨ Features

- Convert Celsius to Fahrenheit
- Convert Fahrenheit to Celsius
- Interactive temperature input
- Simple and user-friendly interface
- Instant conversion results

## 🛠️ Tech Stack

- **Python**
- **Streamlit**

## 📐 Conversion Formulas

### Celsius to Fahrenheit

**Fahrenheit = (Celsius × 1.8) + 32**

### Fahrenheit to Celsius

**Celsius = (Fahrenheit − 32) / 1.8**
